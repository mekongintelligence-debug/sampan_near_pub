# fixtures/vectors

Shared test vectors for Rust and TypeScript (M2, `docs/FORMATS.md`). Generated by `node scripts/gen-vectors.ts`, which adds missing vectors and never overwrites existing ones. `MANIFEST.sha256` pins every file; tests fail if a vector changes. Changing an existing vector needs lead approval.

Vectors hold only public keys and signatures. Accounts in vectors use the never-deployed namespace `*.vectors-only.testnet` (lead decision on audit M2-05, 5 November 2026); the seed phrases are public by design, so these keys must never be used on any network. Regenerated once with lead approval on 5 November 2026. Test keys are derived from fixed seed phrases inside the generator at run time and are never written.
