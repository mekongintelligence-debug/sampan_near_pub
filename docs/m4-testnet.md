The results files hold only the latest run of each command (audit M4-09).

**How the agent is set up.** The agent account's full-access key belongs to the operator and is used only by `scripts/m4/setup.mjs` and `scripts/m4/edge-cases.mjs`. The agent process runs as a separate OS user (`sampan-agent`), so it cannot read the operator's environment or `.secrets/` (audit M4-02). It receives, in a private temporary directory, only a function-call key with receiver = the gate, methods = `purchase`, allowance 0.2 NEAR, plus the public demo state. It refuses to start if any credential-like variable is in its environment, and checks its own key on chain before acting (function-call only, exactly `gate.purchase`, with an allowance); it does not check the account's other keys (audit M4-09). Outbound traffic goes through the machine's proxy without a host limit (accepted: the agent is scripted).

## Findings from the testnet runs
- **M4-01, the order cap counts refusals (availability, no funds at risk).** On the first run the gate's testnet config allowed 8 anchored receipts per mandate; 6 refused injections plus 2 releases used them all, and the third valid order was refused with `order_cap` (unanchored, [tx](https://testnet.nearblocks.io/txns/DBsz31UHPTJxB6cvrPu9rpEWmjtj8EsppC2kR7BWEFLN)). Refusals must count, because each receipt costs the gate storage, so an agent that is injected repeatedly can block its own mandate but cannot move funds. Fix: size `max_orders_per_mandate` for expected refusals. Testnet now uses 16 orders and 4 open mandates, so the reservation still fits the gate's balance. The gate was reset and re-initialised (`scripts/m3/reset-testnet-gate.mjs`, `testnet-run.mjs --init-only`). **Decision for the lead:** the mainnet value.
- **Allowance sizing.** A `purchase` with 150 Tgas prepaid was refused with 0.1 NEAR allowance and accepted with 0.2 to 0.25 NEAR. **Assumption:** the protocol checks the allowance against the prepaid gas at a pessimistic gas price and then charges only the gas actually burnt; this is inferred from these runs, not checked against nearcore.
